Quick Install (Minecraft Java 26.3)

Download the latest 5ifthNN-0.2.0.jar directly from GitHub Releases and place it in .minecraft/mods/ alongside Fabric API and ViaFabricPlus.

# Required mods in .minecraft/mods/

- ViaFabricPlus 5.1.3+ (for 1.8 PvP BedWars servers)
- 5ifthNN-0.2.0.jar (~184 KB, ONNX Runtime bundled)

Recording & Sharing Datasets

Press F9 once to record across back-to-back BedWars matches. Hubs, waiting cages, deaths, chat, and teleports (>6b/tick) are tagged and scrubbed automatically so training windows never cross match boundaries.

Run /5nn share to export a clean .zip and upload it in #submit-datasets on Discord. The server bot verifies SHA-256 hashes, blocks duplicates, archives files, and assigns ● Data Recorder (1+) and ★ Top Contributor (5+ or 10+ MB) roles.

Audit, Train & Export ONNX (Python / Colab L4)

cd python && pip install -r requirements.txt

# 1. Audit recordings before spending Colab credits
python3 -m fifthnn.audit path/to/recordings/

# 2. Behavior Cloning bootstrap (2x mirror augmentation)
python3 -m fifthnn.train_bc --data_dir ./recordings --out checkpoints/fifthnn_bc.pt --epochs 25

# 3. KL-Anchored PPO self-play + INT8 ONNX export (~2.0 MB)
python3 -m fifthnn.export_onnx --ckpt checkpoints/fifthnn_ppo.pt --out models/fifthnn_v1.onnx --quantize_int8
